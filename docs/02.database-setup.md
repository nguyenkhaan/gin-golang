# Cấu hình cơ sở dữ liệu và Migration

## 1. Khai báo biến môi trường

Trước tiên, hãy khai báo một số biến môi trường vào `.env`

## 2. Khai báo GORM Model

- Để sử dụng uuid cho trường ID bên trong Model, chúng ta sẽ cài đặt thêm package: `go get -u github.com/google/uuid`

**Khai báo các Model**: Chi tiết về cú pháp GORM, các bạn có thể đọc tại trang chủ của họ 

```go
//userModel.go 
type UserModel struct {
	gorm.Model
	ID uuid.UUID `gorm:"primaryKey;type:uuid;default:uuid_generate_v4()"`
	Username string `gorm:"unique"`
	Password string 
	CreatedAt time.Time 
	UpdatedAt time.Time 

}
```

```go
//todoModel.go 
type TodoModel struct {
	gorm.Model 
	ID uuid.UUID `gorm:"primaryKey;type:uuid;default:uuid_generate_v4()"`
	Title string 
	Content string `gorm:"default:''"`
	CreatedAt time.Time 
	UpdatedAt time.Time 
	DeletedAt gorm.DeletedAt `gorm:"index"`
	//Define the foreign key 
	User UserModel
} 
```

## 4. Kết nối database

```go
//internal/db/database.go 
import (
	"cloudian/cloudian-restful/internal/config"
	"log"
	"gorm.io/driver/postgres"
	"gorm.io/gorm"
)

var DB *gorm.DB 

func ConnectDB() {
	var err error 
	dsn := config.GetEnvVar("DB_URL")
	DB, err = gorm.Open(postgres.Open(dsn) , &gorm.Config{})
	if err != nil {
		log.Fatal("Failed to connect to database") 
	}
}
```

Khai báo các kết nối đến database để sử dụng 

## 5. Database Migration

```go
//migrate/migrate.go
import (
	"cloudian/cloudian-restful/internal/config"
	"cloudian/cloudian-restful/internal/db"
	"cloudian/cloudian-restful/internal/model"
	"flag"
	"log"

	"gorm.io/gorm"
)

//This function will auto run when in the package main file
func init() {
	config.LoadEnvVariables() 
	db.ConnectDB() 
} 
func MigrateUp(db *gorm.DB) error {
	return db.AutoMigrate(
		&model.UserModel{}, 
		&model.TodoModel{}, 
	)
}
func MigrateDown(db *gorm.DB) error {
	return db.Migrator().DropTable(
		&model.UserModel{},  
		&model.TodoModel{}, 
	)
}	

func main() {
	//We will support flag: --up or --down to decide whether run MigrateUp() or MigrateDown()
	//Syntax (flag package): up := flag.Bool(flagName, defaultValue, description) ----> up is a pointer 
	//Provide a flagNamer into run command. If we don't set the flagName in the command, *up will become default value 
	up := flag.Bool("up", false, "Run migration up") //If we don't pass --up to commands, *up = false 
	down := flag.Bool("down", false, "Migration down") 
	flag.Parse() 
	if *up {
		if err := MigrateUp(db.DB); err != nil {
			log.Fatal("Error while running migration: ", err)
		}
	} 
	if *down {
		if err := MigrateDown(db.DB); err != nil {
			log.Fatal("Error while downing migration: ", err) 
		}
	}
}
```

Mỗi khi chúng ta muốn migrate up database thì chạy lệnh `go run migrate/migrate.go --up`. Khi muốn drop các table thì chạy lệnh `go run migrate/migrate.go --down`
