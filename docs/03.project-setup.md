# Khởi động server, endpoints và Router Group

## 1. Khởi động server

```go
// main.go 
func main() {
    r := gin.Default() 
    r.Run(":8000")
}
```

Khi chúng ta chạy thì một server sẽ được phục vụ ở port 8000 

Bây giờ chúng ta sẽ thêm một route đơn giản vào bên trong file `main.go`. Hãy thêm đoạn code dưới vào giữa 2 lệnh 

```go
r.GET("/health" , func (ctx *gin.Context) {
    ctx.JSON(200, gin.H{
        "message": "Build with Cloudian 💙 Cloud 
    })
})
```

Truy cập link: `http://localhost:8000/health`

## 2. Các thành phần của endpoint

Tiếp theo là làm sao để mà lấy được mấy cái param và query trên thanh URL 

Gin hỗ trợ 2 hàm là `ctx.Param()` và `ctx.Query` để có thể lụm được 2 thằng này (và chắc chắn tụi nó là string) 

```go
//Param 
r.GET("/product/:productId" , func(ctx *gin.Context) {
	productId := ctx.Param("productId") 
	ctx.JSON(200 , gin.H{
		"data": "Thong tin user", 
		"productId": productId, 
	})
})
// Query 
r.GET("/product/info" , func(ctx *gin.Context) {
	price := ctx.Query("price") //Neu nhu khong lay duoc gi thi no se tien hanh tra ve chuoi "" (tu lay ve gia tri default cua string)
	ctx.JSON(200 , gin.H{
		"message": "Build with Cloudian 💙 Cloud", 
		"price": price, 
	})
}) 
```

## 3. Router Group

Đến đây chắc các bạn cũng biết cách để khai báo một controller rồi. Bây giờ chúng ta sẽ refactor lại một chút. 

Thay vì viết toàn bộ trong `main.go`, ta sẽ phân ra 3 thư mục:

- `internal/controller`: Chứa các hàm controller 
- `internal/service`: Chứa logic xử lý chính cho controller 
- `api/route.go`: Thực hiện nhóm các router -> into Router Group. 

**Cấu trúc thư mục**:

```
GIN/
├── api/
│   └── route.go
├── cmd/
│   └── api/
│       └── main.go
└── internal/
    └── controller/
        └── userController.go
```

```go
//userController.go 

func GetAllUsers(ctx *gin.Context) {
	ctx.JSON(200, gin.H{
		"message": "List all users v1", 
	})
}

func GetDetailUser(ctx *gin.Context) {
	ctx.JSON(200, gin.H{
		"message": "List user detail information", 
	})
} 

func CreateUser(ctx *gin.Context) {
	ctx.JSON(201, gin.H{
		"message": "Create a new user", 
	})
}

func UpdateUser(ctx *gin.Context) {
	ctx.JSON(200, gin.H{
		"message": "Update user information", 
	})
}

func DeleteUser(ctx *gin.Context) {
	ctx.JSON(200, gin.H{
		"message": "Delete user successfully", 
	})
}
```

Trong file route.go, chúng ta sẽ đăng ký các API Route bằng hàm `Group` 

```go
func RegisterRouter(r *gin.Engine) {
	api := r.Group("/api") 
	{
		user := r.Group("/user") 
		{
			user.GET("/"  , controller.GetUser) 
			user.POST("/" , controller.CreateUser) 
		}
	}
}
```
