
# Thiết lập dự án và Dependencies

## 1. Cài đặt và sử dụng Air

- air là một công cụ giống nodemon. Giúp chúng ta có thể tự động reload lại server mỗi khi có sự thay đổi trong dự án. 

- Install air: `curl -sSfL https://goblin.run/github.com/air-verse/air | sh` 

## 2. Thiết lập project

- `air init`: Khởi động dự án với air. Lệnh này sẽ tạo ra một file air.toml, chứa các cấu hình air cần thiết cho dự án 
- `go mod init <path_name>`: Tạo file go.mod, quản lý dự án Golang (các depedency) 

path_naem chính là cái mà chúng ta sẽ dùng để import package trong dự án. Các package muốn import đều phải thực hiện import từ `path_name`

## 3. Cấu trúc thư mục

```md
GIN/
├── api/    
├── cmd/    
├── docs/
│   └── guide.md
├── internal/
│   ├── config/
│   ├── handler/
│   ├── middleware/
│   ├── model/
│   └── service/
├── tmp/
├── .air.toml
├── .gitignore
├── go.mod
└── README.md
```
**Giải thích**:

- api/: Quản lý versioning API. Giúp hạn chế sự phá vỡ khi tiến hành thay đổi, không ảnh hưởng tới cấu trúc của các API khác 
- cmd/: entry point cho ứng dụng. Chứa các subfolder về loại ứng dujgn mà chúng ta sẽ build. Ví dụ: `cmd/api` cho RESTFUL API, `cmd/grpc` cho grpc service hoặc `cmd/cli` cho CLI application. Bên trong thì sẽ có file `main.go`

## 4. Cài đặt dependency: `go get` vs `go install`

- Cả 2 đều là lệnh để cài đặt các thành phần phù hợp cho dự án. Tuy nhiên từ Go 1.16 trở đi đã có nhiều khác biệt: 

`go get`: Cài đặt dependency vào dự án code. Ví dụ: GORM, Gin, driver-postgres... 

`go install`: Cài đặt 1 công cụ CLI từ golang, dùng để hỗ trợ dự án. Ví dụ: `air` => Cài thằng vào folder bin của laptop nên chúng ta có thể xài nó ở cả các vị trí bên ngoài dự án. 

Bây giờ chúng ta sẽ tiến hành cài đặt dependency cho dự án. Các lệnh cài đặt package được viết bên dưới: 

```bash
go get -u github.com/gin-gonic/gin # Gin Backend Framework
go get -u gorm.io/gorm # GORM for working with PostgreSQL Database
go get -u gorm.io/driver/postgres # GORM driver for PostgreSQL
go get github.com/joho/godotenv # For loading env variables in Golang
```
