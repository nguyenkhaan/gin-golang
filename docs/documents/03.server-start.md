# Khởi động server, endpoints và Router Group

## 1. Khởi động server

```go
// main.go 
func main() {
    s := fuego.NewServer()  
    s.Run()
}
```

Khi chúng ta chạy thì một server sẽ được phục vụ ở port 9999 

Bây giờ chúng ta sẽ thêm một route đơn giản vào bên trong file `main.go`. Hãy thêm đoạn code dưới vào giữa 2 lệnh 

```go
fuego.Get(s, "/health", func(ctx fuego.ContextNoBody) (map[string]any , error) {
	return map[string]any{
		"message": "Your app is running", 
		"notification": "Build with Cloudian Love Cloud", 
	}, nil 
})
```

Truy cập link: `http://localhost:9999/health`

## 2. Các thành phần của endpoint

Tiếp theo là làm sao để mà lấy được mấy cái param và query trên thanh URL 

Fuego hỗ trợ 2 hàm là `ctx.QueryParam` và `ctx.PathParam` để có thể lụm được 2 thằng này (và chắc chắn tụi nó là string) 

Fuego hỗ trợ hàm `ctx.Body()` để lấy được JSON body. 

```go
//Param 
fuego.Get(f , "/user/{id}", func(ctx fuego.ContextNoBody) (string , error) {
	param := ctx.PathParam("id") 
	return param, nil 
})
// Query 
fuego.Get(f, "/user", func(ctx fuego.ContextNoBody) (string , error) {
	limit := ctx.QueryParam("limit") 
	offset := ctx.QueryParam("offset") 
	return limit, nil 
})
//JSON 
fuego.Post(f, "/user", func(ctx fuego.ContextWithBody[T]) (string , error) {
	body, err := ctx.Body() 
	println(body) 
	return body, err 
})
```




## 3. Router Group

Đến đây chắc các bạn cũng biết cách để khai báo một controller rồi. Bây giờ chúng ta sẽ refactor lại một chút. 

Thay vì viết toàn bộ trong `main.go`, ta sẽ phân ra 3 thư mục:

- `internal/controller`: Chứa các hàm controller 
- `internal/service`: Chứa logic xử lý chính cho controller 
- `api/route.go`: Thực hiện nhóm các router -> into Router Group. 

**Cấu trúc thư mục**:

```
FUEGO/
├── api/
│   └── route.go
├── cmd/
│   └── api/
│       └── main.go
└── internal/
    └── controller/
        └── userController.go
```

```go
//userController.go 
func GetUsers(ctx fuego.ContextNoBody) (string , error) {
	return "Get all user successfully", nil 
} 
func GetDetailUser(ctx fuego.ContextNoBody) (string, error) {
	return "Get all user successfully", nil 
}	
func CreateUser(ctx fuego.ContextWithBody[map[string]any]) (string, error) {
	return "Create user successfully", nil 
}	
func UpdateUser(ctx fuego.ContextWithBody[map[string]any]) (string, error) {
	return "Update user successfully", nil 
}	
func DeleteUser(ctx fuego.ContextNoBody) (string, error) {
	return "Delete user successfully", nil 
}	
```

Trong file route.go, chúng ta sẽ đăng ký các API Route bằng hàm `Group` 

```go
func RegisterRouter(s *fuego.Server) {
	api := fuego.Group(s, "/api") 
	user := fuego.Group(api, "/user" , option.Tags("User")) 
	fuego.Get(user, "/" , controller.GetUsers) 
	fuego.Post(user, "/" , controller.CreateUser)
	fuego.Delete(user, "/{id}", controller.DeleteUser) 
	fuego.Get(user, "/{id}" , controller.GetDetailUser)
}
```
