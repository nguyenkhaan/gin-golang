
## 1. Struct Tag 
Chúng ta sẽ sử dụng struct tag để thêm metadata cho các trường trong struct => Các thư viện khác có thể đọc và xử lý 

**Cú pháp**: `key:"value" key:"value" key:"value"`

## 2. Validator cho: JSON, query, param 

### Body 
Khai báo dto 
```go 
type CreateUserDto struct {
    Username string `json:"username" binding:"required"` 
    Password string `json:"password" binding:"required"`
}
```

Bên trong các hàm controller, sử dụng `ctx.ShouldBindBodyWithJSON` để có thể validate request được gửi đến 

```go 
func CreateUser(ctx *gin.Context) {
    var request dto.CreateUserDto 
    if err := ctx.ShouldBindBodyWithJSON(request); err != nil {
        ctx.JSON(200 , gin.H{
            "error": err.Error(), 
        })
        return 
    }
}
```

### Query 

```go 
type GetUserQuery struct {
    Limit int `form:"limit" binding:"required,numeric,gte=0"`
    Offset int `form:"offset" binding:"required,numeric,gte=0"`
}
```

```go
//userController.go 
func GetUsers(ctx *gin.Context) {
    var query GetUserQuery 
    if err := ctx.ShouldBindQuery(&query); err != nil {
        // raise exception 
    }
} 
```
